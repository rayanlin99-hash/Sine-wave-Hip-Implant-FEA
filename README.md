# Sine-wave Hip Implant FEA

Basic ODB post-processing for implant expansion, interface motion, cortical stress and initial bone resorption. **All six scripts read ODB files directly.** No previously exported NPZ, pairing JSON or local analysis files are required.

## Requirements

Use **Abaqus 2024 Python** (Python 3.10 and its bundled NumPy), or a compatible Python 3 Abaqus version. ODBs must open in that Abaqus version. Run the commands below from **Abaqus Command**, with this repository as the working folder. Standard Python alone does not provide `odbAccess`.

Keep `odb_utils.py` beside the six scripts; it contains their shared field-reading and C3D4 geometry functions.

## Required ODB contents

| Analysis | Required information |
|---|---|
| Expansion | C3D4 implant mesh; initial and final `U` in a completed static step |
| Contact/slip | Implant-side `CPRESS`, `CSLIP1`, `CSLIP2` for the same contact pair; `RF` at each saved frame |
| Local pair distance | C3D4 implant and cancellous-bone interface surfaces (default: `MIDDLE`); initial and subsequent `U`; `RF` at each saved frame |
| Gruen stress ratios | Intact and implanted cortical meshes; final `S`; instance-level element sets `G1`–`G7` |
| Bone resorption | Intact and implanted cortical meshes; final `SENER`; final `U` when NLGEOM is enabled |
| Resorption summary | The `RESORP_S035` ODB generated by script 05 |

Input coordinates/displacements use **mm**, stress/energy density use **MPa**, and forces use **N**. The cortical comparisons require matching C3D4 node/element labels, connectivity and reference coordinates, with consistent materials and loading. Missing output fields cannot be reconstructed from an ODB that never saved them.

## Run

Replace `embedding.odb`, `implanted.odb` and `intact.odb` with your files. Replace instance/surface names with those in your model; the names below are examples from the solid model. Quote paths containing spaces. Results are written under `results/`.

**1. Expansion at 21 heights, Z = 27–77 mm**

```sh
abaqus python 01_expansion.py --odb embedding.odb --instance SOLID-1 --output results/expansion.json
```

Selects the lateral/medial section extrema and follows their fixed material locations. Output is final minus initial 3D distance in **µm**. X is unrestricted; initial U must be zero.

**2. Maximum contact pressure and slip versus load**

```sh
abaqus python 02_contact_metrics.py --odb implanted.odb --instance SOLID-1 --output results/contact.json
```

Computes `sqrt(CSLIP1² + CSLIP2²)` at each node before taking the maximum, in **mm**. Also reports the maximum over nodes with CPRESS > 1e-6 MPa. If several contact pairs exist, supply `--pair "exact contact-pair suffix"`; the error message lists available suffixes. The saved-frame curve uses actual `RF`, not a prescribed load ramp.

**3. Current implant–bone distances at Z = 40 and 70 mm**

```sh
abaqus python 03_fixed_pair_distance.py --odb implanted.odb --implant-instance SOLID-1 --bone-instance ZCANCELLOUS-1 --output results/distance.json
```

The script intersects the bone interface at X = 0 and each reference Z, selects its lateral/medial extrema, finds the nearest implant surface point, and then finds that point's nearest bone surface point. Both triangular-face interpolation weights remain fixed through loading. Output includes the selected faces/weights, current distances in **µm** (initial separation retained), actual loads and initial/final values.

Use `--heights 40 70` to specify heights, and `--implant-surface NAME --bone-surface NAME` if the interface surfaces are not named `MIDDLE`. The selection assumes negative Y is lateral and positive Y is medial.

**4. G1–G7 and pooled stress ratios**

```sh
abaqus python 04_gruen_stress.py --reference intact.odb --implant implanted.odb --reference-instance CORTICAL --implant-instance CORTICAL --output results/stress.json
```

Uses unaveraged integration-point von Mises stress and undeformed element volumes. Ratios are dimensionless (implanted/intact). Total is calculated over the G1–G7 union. The anatomical zones must already exist as element sets in both ODBs; the script does not infer them from geometry.

**5. Initial bone resorption, s = 0.35 only**

```sh
abaqus python 05_Bone_Resorption_Cloudmap.py --reference intact.odb --implant implanted.odb --reference-instance CORTICAL --implant-instance CORTICAL --output results/resorption
```

Uses the local intact-bone stimulus, B = 1 and density = 1760 kg/m³. Only the negative rate is retained, in **kg m⁻³ ctu⁻¹**; no iterative remodelling is performed. Open `results/resorption/implanted_RESORP_S035.odb` in Abaqus/CAE and select `RESORP_S035` to view the result. The filename is based on the implanted ODB's name.

**6. Whole-cortex resorption statistics**

```sh
abaqus python 06_resorption_summary.py --odb results/resorption/implanted_RESORP_S035.odb --output results/resorption_summary.json
```

Reports the volume-weighted mean rate and potential resorption-region volume fraction (%). Both denominators include zero-rate elements. This fraction describes regions predicted to resorb initially, not the amount of bone lost.

Scripts 01–05 use the last step by default, which must be a completed static step; add `--step STEP_NAME` to select another completed static step. Inputs are opened read-only. Script 05 refuses to overwrite an existing result ODB; use another output folder for a repeat run. JSON output files are replaced when the same output filename is used.

## Validation

Tested with Abaqus 2024 on the original Solid embedding model and the Solid2_2/intact cortical models. Expansion, contact/slip, automatically selected distances, stress ratios and resorption statistics were checked against the existing numerical results. ODB model files and Abaqus software are not distributed with this repository.
